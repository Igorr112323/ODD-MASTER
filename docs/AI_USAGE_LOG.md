Конкурс «ИИ-разработчик» 2026/27, студенческий проект nanoCAD. Декларация честная: что делал агент, что проверено автоматически, а что нет.

## Что сгенерировано ИИ

- Все файлы каркаса: решения, проекты, конфиги, 9 JSON Schema, ~8 000 строк C#, ~100 тестов, CI, скрипты, 16 ADR, вся документация, демо-артефакты (`docs/demo/`), этот отчёт.
- Нормативные числа **не придумывались**: они перенесены из раздела 8.4 промпта (выписка куратора) в `config/` со статусом `CuratorExtracted`. Всё, чего в выписке нет, оставлено `null` или `Placeholder` с маркером `GOST-NNN`.
- Все предположения об API nanoCAD помечены `SDK-NNN` и вынесены в некомпилируемый адаптер.

## Что НЕ проверено

- Адаптер `src/OddMaster.NanoCAD/` не компилировался: SDK nanoCAD 26 отсутствует. Восемь предположений SDK-001…SDK-008 ждут проверки.
- Переключение на .NET 8 (`-p:OddTargetFramework=net8.0`) не проверено: в песочнице только SDK 3.1.102.
- Покрытие кода не измерялось (нет coverlet), мутационное тестирование не запускалось (нет Stryker). Одна ручная мутация выполнена.
- Нормативные значения не сверены с официальным текстом ГОСТ Р 52290-2024: у агента его не было. 21 маркер `GOST-NNN` — очередь проверки студента.
- Цвета, пиктограммы, высота надписей, ширина внутренней каймы, форма ведомости Приказа №49 — заглушки. Выводы помечены «ЧЕРНОВИК».
- Боевая карта замен 2004 → 2024 пустая; все демо-замены синтетические и помечены «ДЕМО».
- PDF из Markdown не сделан: нет конвертера; по условию достаточно MD + CSV.
- Визуальная корректность SVG не проверялась человеком (только разбор как XML и golden-сравнение).

## Что должен сделать автор

1. Сверить top-10 из `docs/VERIFICATION_QUEUE.md` по официальным рисункам прил. Д.
2. Самостоятельно заполнить раздел «Что сделал ИИ, а что вы» в `docs/EXPLAIN_FOR_AUTHOR.md` — там оставлен шаблон.
3. Проверить SDK на nanoCAD 26, закрыть SDK-NNN, собрать адаптер на Windows.
4. Переключить TFM на .NET 8 и убрать резервный bootstrap.
