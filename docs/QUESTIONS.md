# Вопросы куратору и противоречия

Формат: ID | тип | вопрос | решение по умолчанию (обратное, предварительное) | где отмечено.

| ID | Тип | Вопрос / противоречие | Решение по умолчанию | Где |
|---|---|---|---|---|
| Q-001 | Блокирующий для .NET 8 | Промпт требует .NET 8, но в среде нет dotnet и нет доступа к `dot.net`/NuGet. Доступен только SDK 3.1.102 из npm-зеркала. | Собирать на 3.1.102, TFM в одной переменной `OddTargetFramework`, `global.json` с `rollForward: latestMajor`. На неделе 1 переключить на `net8.0`. | ADR-0009, `INVENTORY.md`, отчёт |
| Q-002 | Блокирующий для тестов | Требуются xUnit, coverlet.collector, JsonSchema.Net (MIT), но `api.nuget.org` недоступен. | Свой микро-раннер (`OddFact`, `TestRunner`) + цель `VSTest`; свой валидатор конфигов; схемы как документация формы. Покрытие **не измерено**, в отчёте без процентов. | ADR-0014, `DEPENDENCIES.md`, отчёт |
| Q-003 | Противоречие промпта | П. 5.5 требует ветку `night/skeleton-01`, но платформа создала ветку `arena/649405ec-odd-master` и привязала к ней сессию; там же сказано «если платформа сама создаёт ветку — работать в ней». | Работаем в ветке платформы, не переименовываем. | отчёт, раздел 10 |
| Q-004 | Нормативный | Точная форма ведомости ТС ОДД по Приказу №49 неизвестна (в факт-фундаменте только состав ПОДД). | Черновик колонок из M5; GOST-011 на форму. Всё, что похоже на официальную форму, помечается «ЧЕРНОВИК». | `VERIFICATION_QUEUE.md`, GOST-011 |
| Q-005 | Нормативный | Ширина внутренней каймы и высота надписей есть только на рисунках прил. Д; текста ГОСТ у агента нет. | `null` + GOST-001/002, для отрисовки `Placeholder` → водяной знак «ЧЕРНОВИК». | ADR-0004, GOST-001, GOST-002 |
| Q-006 | Нормативный | 6 несостыковок в выписке (8.5): что из них ошибка распознавания PDF, а что — реальная особенность стандарта? | Валидатор показывает 1–4 как предупреждения, 5–6 — в очередь проверки. Данные не меняем. | `VERIFICATION_QUEUE.md`: GOST-007, GOST-010, GOST-020, GOST-021 |
| Q-007 | Архитектурный | Профиль ГОСТ 32945-2014: пять типоразмеров 1–5, но значения куратор не извлекал. | Пустая заготовка со статусом `Unverified`, генератор на таком профиле возвращает находку. | ADR-0003, GOST-015 |
| Q-008 | Демо | Боевая карта замен 2004→2024 пустая; чем наполнить демо? | Синтетическая карта с явной пометкой «ДЕМО» в `tests/fixtures/actualizer/`, баннер на всех выводах. | ADR-0010, отчёт |
| Q-009 | Культура | .NET Core 3.1 ищет ICU до версии 67, в среде ICU 72. | `CLR_ICU_VERSION_OVERRIDE` в `scripts/dotnet-env.sh`; тесты явно гоняются под `ru-RU` и `en-US`. | `INVENTORY.md`, отчёт |
| Q-010 | SDK | Все ориентиры по MultiCAD .NET взяты из статей 2014–2017; nanoCAD 26 может отличаться. | Каждый вызов помечен `SDK-NNN`, адаптер не компилируется в CI, в отчёте «не компилировался». | `SDK_ASSUMPTIONS.md`, ADR-0002 |

| Q-011 | SDK / блокирующий на неделе 1 | Нужен вузовский доступ к SDK nanoCAD 26; без него адаптер останется не собранным. | Адаптер в отдельном solution, восемь `SDK-NNN`, план в `BUILD_NANOCAD.md`. | `SDK_ASSUMPTIONS.md`, отчёт раздел 9 |
| Q-012 | Инструментальный | Промпт просит .NET 8, но переключение TFM на .NET 8 не проверено в песочнице. | Оставить `netcoreapp3.1` как проверенный TFM, переключить на неделе 1 на машине с .NET 8 и прогнать `verify.sh`. | ADR-0009, E-019 |
| Q-013 | Нормативный | Является ли Д.9 частью перечня п. 3.13 или это пропущенная таблица? | Валидатор показывает GAP-001 как предупреждение, данные не меняем. | `NORMATIVE_SOURCES.md`, GOST-014 |
| Q-014 | Нормативный | Нужна ли отдельная проверка «табличка без основного знака» для всех табличек группы 8 или только для 8.2.1? | Сейчас R002 проверяет все знаки группы 8, статус `Unverified`. | `config/rules/controls.json`, GOST-017 |
| Q-015 | Формат | Достаточно ли MD + CSV вместо PDF отчёта аудитора? | По условию задания PDF необязателен; конвертера в песочнице нет. | `RED_TEAM.md` проход №2, отчёт раздел 10 |
