## Что смотрит студент

1. Скачать `sign-previews` (`gh run download <id> -n sign-previews`), открыть `contact-sheet.png`.
2. Сверить форму носителей с прил. Д (Д.2–Д.9) и наименования с прил. А.
3. Отметить расхождения здесь же и завести/закрыть `GOST-NNN`.
4. После оцифровки пиктограмм обновить эталоны **одним коммитом с этим файлом** (§9.4).
