- п. 3.1 — восемь групп знаков;
- п. 3.2 — номенклатура в табл. А.1–А.8, изображения на масштабной сетке в прил. Б;
- п. 3.3 — формат номера `группа.знак[.разновидность[.разновидность]]` → `SignNumber`;
- п. 3.4 — шрифт прил. В, литерные площадки прил. Г; при электронной вёрстке допустим Arial Bold;
- п. 3.5 — значения параметров по табл. Д.1 → `config/norms/parameters.json`;
- п. 3.11 — необязательные символы на знаке 6.4;

- п. 3.13 — размеры по табл. Д.2–Д.8 (фактически есть и Д.9 → GOST-014);
