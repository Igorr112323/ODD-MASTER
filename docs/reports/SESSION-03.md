## 8. Топ-5 рисков для приза

1. **Репозиторий PUBLIC** — SDK-часть нельзя начать; при этом конкурс может требовать публичный репозиторий.
   Решение за студентом (Q-019), агенту менять видимость запрещено.
2. **Пиктограммы — заглушки.** 20+ знаков имеют на месте пиктограммы стрелку или пустое поле;
   без оцифровки по прил. Б продукт выглядит «почти правильным», а это хуже честного черновика.
3. **Нет эмулятора и контракта** — значит, нет ни одного доказательства поведения, только геометрия.
   Это следующий по важности шаг после нормативных данных.
4. **Куратор не подтвердила цвета** — MVP-2 держится на её таблице; ошибка в данных размножится по всем артефактам.
5. **Лимит DXF-работ.** CURATOR-03 §5 ограничил DXF 20 % сессии; в сессии 03 DXF-стенд занял больше,
   дальше приоритет — сценарии и эмулятор, а не «экран».
