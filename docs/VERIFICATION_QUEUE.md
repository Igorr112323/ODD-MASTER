# Очередь проверки нормативных данных (GOST-NNN)

Правило: неизвестное значение = `null` в конфиге + запись здесь. Статус `StudentVerified` ставит **только человек** после сверки с официальным текстом. Агент не имеет права его ставить. Порядок в таблице устойчив; идентификаторы не переиспользуются.

## Как работает автоматическая проверка

`ConfigValidator.CheckMarkers` собирает все `GOST-NNN` из `config/`, сравнивает с этой таблицей и сообщает о «висячих» маркерах. Тест `MarkerRegistryTests` делает то же самое для кода, конфигов и документов. Добавляя маркер, сначала добавьте строку сюда.
