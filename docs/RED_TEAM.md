# Красная команда: найденные проблемы

Три прохода: после M3, после M6, перед финалом. Критичное исправлено сразу; остальное унесено в бэклог с причиной.

## Проход №1 (после M3)

| # | Находка | Критичность | Действие |
|---|---|---|---|
| 1 | `Golden.CheckText` молча создавал отсутствующий эталон — тест «проходил», ничего не проверив | Высокая | Исправлено: без `ODD_UPDATE_GOLDEN=1` отсутствие эталона — ошибка. Добавлен тест M3-S09 |
| 2 | `<metadata>` в SVG был «просто текстом» с `key=value` — машиночитаемости нет | Средняя | Исправлено: элемент `odd:sign` с атрибутами и своим namespace |
| 3 | JSON Schema проверялись только на синтаксис; несоответствие конфига схеме не ловилось | Высокая | Исправлено: `CheckConfigsMatchSchemas` сверяет `required` схемы с корнем конфига. Полноценный движок схем по-прежнему недоступен (нет NuGet) — отражено в ADR-0014 |
| 4 | Демо-команды `scheme/check/actualize` пока пустые заглушки | Средняя | Принято: реализуются в M8; в отчёте это не скрывается |
| 5 | В `RoundedPolygon` тест зеркальности сравнивал точки в порядке обхода; зеркало меняет направление | Средняя | Исправлено: сравнение как множество точек с допуском |
| 6 | `VerifSummary.IsDraft` срабатывает и на `Unverified` — почти все знаки черновики | Низкая | Принято осознанно: цвета POC-знаков действительно не сверены |
| 7 | Профиль 32945-2014 пуст, `SizeResolver` возвращает находку; галереи для него нет | Низкая | Принято: значения не извлекались куратором (GOST-015) |
| 8 | Свойство `Corner.Radius` в `RoundedPolygon` задаётся, но не используется | Низкая | Исправлено: убрано из модели (мёртвый код) |
| 9 | `SvgSignRenderer` использует `StringBuilder.AppendLine()` → на Windows CRLF | Средняя | Исправлено: финальная нормализация `\r\n` → `\n` (была с M3) |
| 10 | `ConfigValidator` предупреждает о маркерах, которые есть в очереди, но не в конфигах (GOST-007/010/020) | Низкая | Принято: это маркеры кода/документов; предупреждение информирует, а не блокирует |

Ручная мутация (проверка тестов): замена `multipleOf: 10` на `1` в `config/norms/parameters.json` уронила тест M1-C07 и M2-G05; возврат значения восстановил зелёное состояние. Проверено в M3.

## Проход №2 (после M6)

| # | Находка | Критичность | Действие |
|---|---|---|---|
| 1 | `NormRef` не переопределял `ToString()`: в отчёте аудитора вместо «ГОСТ Р 52290-2024, п. 3.13» печаталось `OddMaster.Core.Norms.NormRef` | Высокая | Исправлено: `ToString() => Describe()`, эталоны обновлены; добавлен тест на отсутствие имени типа в отчёте |
| 2 | Текст причины `ParameterNorms` интерполировал `decimal` в текущей культуре: при ru-RU «2,35», при en-US «2.35» — нарушена детерминированность | Высокая | Исправлено: `Inv(decimal)` с InvariantCulture; тест M6-C09 теперь проходит |
| 3 | Правило R003 считало «повтором» знак, стоящий **раньше** начала зоны — находится false-negative | Средняя | Исправлено: ищем только более поздние пикеты; в фикстуру добавлен «висячий» старт E12 |
| 4 | `AuditCsvParser` молча принимал любой заголовок и перепутанные колонки | Средняя | Исправлено: явная проверка заголовка и понятная русская ошибка |
| 5 | R007 для каймы упоминал GOST-008 в тексте, но колонка «Маркер» оставалась пустой | Средняя | Исправлено: маркер пишется в отдельное поле |
| 6 | PDF из Markdown не сделан: в песочнице нет pandoc/wkhtmltopdf, а вендорить конвертер нельзя | Низкая | Принято: по условию допустимы MD + CSV; записано в NIGHT_REPORT |
| 7 | Покрытие кода не измеряется (нет coverlet/NuGet) | Средняя | Принято: ADR-0014 явно фиксирует отсутствие покрытия, тесты перечислены в инвентаре |
| 8 | `SchemeAuditor` проверяет генерацию знаков, но не проверяет построение ведомости | Низкая | Частично: демо M8 строит ведомость; отдельной проверки нет — бэклог |
