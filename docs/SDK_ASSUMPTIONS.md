# Предположения об API MultiCAD .NET / nanoCAD (SDK-NNN)

**Этот реестр — не документация SDK.** Официального SDK nanoCAD 26 в среде агента не было. Всё ниже — ориентиры из публичных статей 2014–2017 (Хабр) и требует проверки на неделе 1. Код адаптера в `src/OddMaster.NanoCAD/` **не компилировался**.

| ID | Что предполагается | Где в коде | Откуда уверенность | Как проверить на неделе 1 | Статус |
|---|---|---|---|---|---|
| SDK-001 | Сборки `mapimgd.dll`, `mapibasetypes.dll`, `imapimgd.dll` лежат в папке SDK `include-x64` | `OddMaster.NanoCAD.csproj` → `$(NanoCadSdkPath)` | публичные статьи 2014–2017 | Получить SDK после регистрации, сверить имена и расположение DLL | не проверено |
| SDK-002 | Пространства имён `Multicad.*` доступны после ссылки на сборки | `HelloCommand.cs` → `using Multicad.Runtime;` (в комментарии) | публичные статьи | Открыть объектную модель SDK в Object Browser | не проверено |
| SDK-003 | Команда регистрируется атрибутом `CommandMethod` | `HelloCommand.cs` → `[CommandMethod("ODD_HELLO")]` (в комментарии) | публичные статьи | Собрать минимальный плагин и вызвать команду в nanoCAD | не проверено |
| SDK-004 | Базовый класс кастомного объекта — `McCustomBase` | `SignObject.cs` → комментарий у `OnDraw` | публичные статьи | Сверить имя базового класса и его сборку | не проверено |
| SDK-005 | У кастомного объекта есть переопределяемый метод отрисовки (`OnDraw`/аналог) | `SignObject.cs` → `OnDraw` | предположение по аналогии | Найти метод в справке SDK, поправить сигнатуру | не проверено |
| SDK-006 | Геометрию можно отдать в САПР через примитивы (отрезок/дуга/текст) из `Multicad.Geometry` | `NanoCadDrawingPort.cs` → все четыре метода `IDrawingPort` | предположение | Проверить типы примитивов, единицы углов и высоты текста | не проверено |
| SDK-007 | Плагин загружается через `NETLOAD`/меню приложений nanoCAD | `docs/BUILD_NANOCAD.md` | публичные статьи | Загрузить собранную DLL в nanoCAD 26 на Windows | не проверено |
| SDK-008 | Целевой фреймворк nanoCAD 26 совместим с .NET 8 | `OddMaster.NanoCAD.csproj`, ADR-0009 | косвенно (Linux/Avalonia) | Уточнить у разработчика вендора требуемую версию .NET | не проверено |

Проверка один-к-одному: тест `MarkerRegistryTests.M1-M02` собирает все `SDK-NNN` из `src/`, `config/`, `tests/`, `docs/` и сверяет с первой колонкой этой таблицы. Добавляя вызов SDK, сначала добавьте строку сюда.

Архитектурный порт: `OddMaster.Core.Ports.IDrawingPort` и `GeometryPortWriter` не содержат ни одного упоминания MultiCAD/Teigha — это проверяет тест M2-G13. Адаптер получает уже готовую геометрию и только преобразует её в примитивы САПР.
