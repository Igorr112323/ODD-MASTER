Скопировать в `docs/feedback/SMOKE-ГГГГ-ММ-ДД.md` **студенту** после сборки адаптера.
Не больше 30 минут работы. Агент не заполняет этот отчёт и не ставит L3 без него.

```

| Шаг | Команда | Ожидаемый результат | Факт | Скриншот |
|---|---|---|---|---|
| 1 | NETLOAD → OddMaster.NanoCAD.dll | плагин загружен без ошибок | ✅/❌ | <файл> |
| 2 | ODD_HELLO | сообщение «ОДД-Мастер: плагин загружен» | ✅/❌ | <файл> |
| 3 | ODD_SIGN 3.24 II 40 | знак на чертеже, размеры по Д.4 | ✅/❌ | <файл> |
| 4 | сохранить/открыть DWG | знак сохраняется и читается | ✅/❌ | <файл> |
| 5 | ODD_SELFTEST (если включён) | JSON-отчёт без ошибок | ✅/❌ | <файл> |

Итог: L3 = ✅/❌. Что сломалось: … . Что нужно агенту: …
```

Правила: скриншоты ≥1600×1200; никаких DLL SDK в git; все найденные расхождения API —
в `docs/SDK_ASSUMPTIONS.md` со ссылкой на `sdk-api.txt` и run.
