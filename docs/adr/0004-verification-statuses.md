# ADR-0004: Статусы проверки данных и пометка ЧЕРНОВИК

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

Официального текста ГОСТ у агента нет; часть значений известна только по выписке куратора, часть — только по рисункам.

## Решение

Четыре статуса: Placeholder, Unverified, CuratorExtracted, StudentVerified. Неизвестное значение = `null` + GOST-NNN. Всё, где использован Placeholder/Unverified, получает `IsDraft = true` и водяной знак «ЧЕРНОВИК». Агент не ставит StudentVerified.

## Альтернативы

Считать выписку куратора окончательной; рисовать заглушки без пометки.

## Последствия

Плюсы: честность, видимость пробелов. Минусы: почти все демо-знаки черновики — это правильно. Статус: принято.
