# ADR-0005: Семантика списков и диапазонов номеров знаков

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

В таблицах ГОСТ встречаются «1.5 - 1.7, 2.4», «6.14.2 - 6.16», «1.1 - 2.4». Нужна предсказуемая проверка вхождения.

## Решение

Номер сравнивается покомпонентно как кортеж: 3.2 < 3.10 < 3.24, 2.3.7 < 2.4. Диапазон «A - B» (дефис/тире, пробелы необязательны) содержит A ≤ N ≤ B. Верхняя граница без подномеров НЕ включает свои разновидности: 6.16.1 не входит в «… - 6.16». Одиночный номер совпадает только сам с собой. Диапазон может пересекать группы.

## Альтернативы

Сравнение строк (3.10 < 3.2); сравнение как double (3.24 > 3.2, но 3.10 → 3.1); включение всех разновидностей верхней границы.

## Последствия

Плюсы: совпадает с таблицами прил. Д. Минусы: нестандартная семантика — описана в EXPLAIN_FOR_AUTHOR и зафиксирована тестами. Меняется только через ADR. Статус: принято.
