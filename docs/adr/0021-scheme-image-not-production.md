# ADR-0021: Изображение для схемы, а не для изготовления

- **Статус:** принято (сессия 02, 28.10.2026).
- **Дата:** 2026-10-28.

## Контекст

Решение куратора (программа «Продукт», §7): модуль рисует условные изображения знаков на схемах ОДД. Чертежи лицевых сторон для производства — территория IndorRoadSign, туда не идём.

## Решение

В данных точно только размеры носителей и типоразмеры по прил. Д — они идут в ведомость. Пиктограммы оцифровываются с прил. Б с погрешностью ±2 мм в натуре; производственные допуски п. 3.15 к нам не применяются. Размер знака на чертеже = условный размер на листе (мм, профиль оформления) × масштаб чертежа, натурный типоразмер — атрибут.

## Альтернативы

Строить производственные чертежи лицевых сторон; применять п. 3.15.

## Последствия

Плюсы: честная граница продукта, меньше нормативных рисков. Минусы: сопоставление с прил. Б всё равно нужно для pictogram. Статус: принято.
