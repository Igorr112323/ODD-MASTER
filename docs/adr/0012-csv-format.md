# ADR-0012: Формат CSV для Excel

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

Excel в русской локали ожидает `;` и запятую в дроби; UTF-8 без BOM ломает кириллицу.

## Решение

CSV: UTF-8 с BOM, разделитель `;`, дробная часть с запятой, кавычки удваиваются, окончания строк `\r\n` (явно, без Environment.NewLine). Числа форматируются InvariantCulture, затем точка заменяется на запятую.

## Альтернативы

UTF-8 без BOM; разделитель запятая; системные окончания строк.

## Последствия

Плюсы: файл открывается двойным щелчком в русском Excel. Минусы: формат завязан на локаль; документирован. Статус: принято.
