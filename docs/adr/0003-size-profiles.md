# ADR-0003: Профили типоразмеров

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

ГОСТ Р 52290-2024 даёт четыре типоразмера I–IV (прил. Д), ГОСТ 32945-2014 — пять 1–5 (прил. А).

## Решение

Типоразмеры — свойство профиля в конфиге. По умолчанию `GOST_R_52290_2024`. Второй профиль — пустая заготовка со статусом Unverified (GOST-015). Генератор получает профиль через конструктор.

## Альтернативы

Зашить четыре типоразмера в enum; хранить размеры в коде.

## Последствия

Плюсы: смена стандарта = новый JSON. Минусы: пустой профиль пока возвращает находку вместо геометрии. Статус: принято.
