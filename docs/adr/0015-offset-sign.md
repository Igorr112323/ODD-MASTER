# ADR-0015: Правило знака смещения от оси

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

Нужно зафиксировать, что «+» означает справа по ходу пикетажа.

## Решение

Смещение `Offset` положительно справа по ходу возрастания пикетажа. Вектор нормали вычисляется как `(dy, -dx)` для единичного направления оси `(dx, dy)` — это правая нормаль. Тест проверяет на оси вдоль +X, что «+» даёт отрицательную Y.

## Альтернативы

Слева = «+»; знак зависит от направления просмотра чертежа.

## Последствия

Плюсы: однозначность в журнале координат. Минусы: студент должен сверить с принятой в ПОДД практикой. Статус: принято.
