# ADR-0011: Группировка строк ведомости ТС ОДД

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

Знаки 3.24 «40» и 3.24 «60» — разные изделия; ведомость должна это различать.

## Решение

Ключ группировки: номер + типоразмер + значение параметра (в канонической строке). Сортировка натуральная по SignNumber. Пустой вход даёт только шапку.

## Альтернативы

Группировать только по номеру; сортировать как строки.

## Последствия

Плюсы: ведомость пригодна для заказа. Минусы: форма не сверена с Приказом №49 (GOST-011). Статус: принято.
