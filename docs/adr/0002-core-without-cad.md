# ADR-0002: Ядро без зависимостей от САПР

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

SDK nanoCAD закрытый, в среде агента отсутствует; ядро должно проверяться на Linux без nanoCAD.

## Решение

`OddMaster.Core` зависит только от BCL. `OddMaster.Render.Svg` → Core. `Demo` → Core + Render.Svg. `NanoCAD` → Core + SDK и живёт в отдельном решении, не собирается в CI. Связь с САПР — через порты `Ports/`.

## Альтернативы

Прямые вызовы MultiCAD в ядре (нельзя тестировать); общая сборка с адаптером (CI красный).

## Последствия

Плюсы: тестируемость, Linux, Avalonia-совместимость. Минусы: нужно писать адаптер дважды при смене API. Архитектурный тест проверяет запрещённые ссылки. Статус: принято.
