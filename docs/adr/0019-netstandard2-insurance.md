# ADR-0019: Страховочная сборка ядра под netstandard2.0

- **Статус:** принято (сессия 02, 28.10.2026).
- **Дата:** 2026-10-28.

## Контекст

CR-15: до закрытия SDK-008 неизвестно, какой рантайм у nanoCAD 26. Если хост окажется .NET Framework, Core на net8.0 не загрузится.

## Решение

Отдельный проект `src/OddMaster.Core.NetStandard` компилирует те же исходники `OddMaster.Core` под `netstandard2.0` с пакетом `System.Text.Json` 8.0.5. В `OddMaster.sln`не входит: это проверка совместимости в CI, а не второй продукт. Из ядра убраны API, отсутствующие в netstandard2.0: `HashCode.Combine` и `string.Replace(string,string,StringComparison)`.

## Альтернативы

Не делать страховку; сразу писать адаптер под net8.0.

## Последствия

Плюсы: ядро остаётся переносимым. Минусы: дублируется компиляция, возможен конфликт версий System.Text.Json с хостом nanoCAD — SDK-008. Если SDK-008 покажет .NET 8, страховку убрать новым ADR. Статус: принято.
