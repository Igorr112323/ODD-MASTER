# ADR-0010: Категории Актуализатора и неверифицированная карта замен

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

ГОСТ 2024 во многом добавляет и разрешает новое, а не отменяет старое. Боевой карты замен у агента нет.

## Решение

Шесть категорий: Replaced, Removed, NeedsDecision, AllowedSimplify, Unchanged, Unknown. Последние две вычисляются по каталогу 2024. Боевая карта пустая (GOST-018). Если применено правило со статусом ниже StudentVerified — баннер «Карта замен не сверена…». Демо-карта помечена «ДЕМО».

## Альтернативы

Только Replaced/Removed; молчаливое применение синтетических правил.

## Последствия

Плюсы: честность, категория «допустимо, но можно упростить» по поправке куратора. Минусы: движок без содержания — студент заполняет карту по таблице различий. Статус: принято.
