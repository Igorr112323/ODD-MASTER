# ADR-0024: Импорт таблицы различий и категория Renamed

- **Статус:** принято (сессия 02, P3).
- **Дата:** 2026-10-28.

## Контекст

Q-008: для демо нужна боевая карта замен из `data/diff-2004-2024.csv`, колонки включают категорию
`Renamed`, которой нет в перечне `MigrationCategory` прогона №1.

## Решение

`DiffMapImporter` читает 8 колонок, строки `Unchanged` не создают правил (движок сам находит номер
в каталоге 2024). `Renamed` отображается в `Replaced` с пояснением в `comment` — визуально это та же
замена номера. Статус строки CSV переносится в `verification`; неизвестный статус → `Unverified`.
Неизвестная категория → `NeedsDecision` (решение человека), а не молчаливое применение.

## Альтернативы

- Добавить `Renamed` в enum (ломает матрицу категорий и отчёты, требует новые golden-файлы).
- Игнорировать неизвестные строки (скрывает проблемы данных).

## Последствия

Плюсы: импорт работает на шаблоне, не выдумывает замены, не теряет строки. Минусы: `Renamed`
не видна как отдельная категория в отчёте — если куратор сочтёт её важной, добавим enum новым ADR.
