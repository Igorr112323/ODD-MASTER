# ADR-0008: UI в будущем — только Avalonia

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

MultiCAD .NET поддерживает Linux с UI на Avalonia; WinForms/WPF привязывают к Windows.

## Решение

В каркасе нет UI. Когда он появится — Avalonia. WinForms и WPF запрещены архитектурным тестом.

## Альтернативы

WinForms (быстрее, но только Windows); WPF; веб-интерфейс.

## Последствия

Плюсы: кроссплатформенность, конкурентное преимущество. Минусы: требуется изучение Avalonia. Статус: принято.
