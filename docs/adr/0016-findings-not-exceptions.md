# ADR-0016: Находки вместо исключений для нормативных проблем

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

Исключения «на всякий случай» скрывают проблемы и ломают пакетную обработку.

## Решение

Все нормативные несоответствия (нет типоразмера, параметр не по Д.1, дубль, пробел данных) возвращаются как `Finding` с RuleId, Severity, NormRef и статусом. Исключения — только ошибки программиста (null-аргумент, битый код).

## Альтернативы

Бросать InvalidOperationException на каждое нарушение.

## Последствия

Плюсы: отчёт содержит все проблемы сразу, а не первую. Минусы: вызывающий код обязан проверять Findings. Статус: принято.
