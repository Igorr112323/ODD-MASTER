# ADR-0014: Свой тестовый раннер вместо xUnit

- **Статус:** см. «Последствия».
- **Дата:** 2026-10-27.

## Контекст

NuGet недоступен, поэтому xUnit/coverlet/JsonSchema.Net поставить нельзя; тесты при этом обязательны.

## Решение

Тестовые проекты — консольные приложения с атрибутом `OddFact`, классом `Assert` и рефлексивным `TestRunner`. `Directory.Build.targets` переопределяет цель `VSTest`, поэтому `dotnet test OddMaster.sln` запускает тесты и возвращает ненулевой код при падении. JSON Schema проверяются на синтаксис и обязательные поля; семантику проверяет `ConfigValidator`. Покрытие **не измеряется**.

## Альтернативы

Не писать тесты; вендорить nupkg в репозиторий; писать тесты на Python.

## Последствия

Плюсы: ноль внешних зависимостей, `dotnet test` работает. Минусы: нет параметрайзд-тестов, нет покрытия, нет Stryker. При появлении NuGet заменить на xUnit (ADR новый). Статус: принято (Q-002).
